1. PROJECT TITLE

Online Judge - Problem Solving Platform

==================================================

2. PROJECT DESCRIPTION

An Online Judge is a system where users can solve programming
problems and submit their Java solutions to be tested automatically.

- What is the system?
  A platform that presents programming problems and automatically
  compiles, runs, and grades the Java solutions submitted by users.

- What problem does it solve?
  It removes the need for a teacher or examiner to manually check
  every solution. The system runs the submitted code against
  predefined test cases and gives an instant verdict
  (Accepted, Wrong Answer, Runtime Error, Compilation Error).

- Who uses it?
  Students (solve problems and earn points) and an Admin
  (manage users and monitor the system).

==================================================

3. MAIN FEATURES

- Login (Users and Admin)
- Admin: Add / Update / Remove Users
- View problems and select one to solve
- Submit a Java solution file
- Automatic compilation of the submitted code
- Run code against test cases (Accepted / Wrong Answer / Runtime Error)
- Score system (earn points when a problem is solved)
- Scoreboard showing all users with their scores
- Refresh Score
- Logout / Exit
