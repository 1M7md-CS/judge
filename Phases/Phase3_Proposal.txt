1. INTRODUCTION

The Online Judge is a problem-solving platform that allows users to
practice programming by solving predefined problems and submitting
Java solutions. The system automatically compiles the submitted code,
runs it against test cases, and gives an instant verdict.

This is the final version of the project. It contains a complete
GUI, a connected MySQL database, full CRUD operations, and an
automatic grading system for solutions.

==================================================

2. PROJECT OBJECTIVES

- Provide a login system for Users and Admins
- Allow the Admin to manage users (Add, Update, Remove, View)
- Provide programming problems to solve
- Allow the user to submit a Java solution file
- Compile and run the solution automatically
- Grade the solution using test cases
- Give instant feedback (Accepted, Wrong Answer, Runtime Error,
  Compilation Error)
- Track user scores and show a leaderboard

==================================================

3. MODULES EXPLANATION

Module 1: Login Module
- The user enters username and password
- The password is hashed with SHA-256 and checked against the
  users table
- On success, the system opens Admin or User dashboard depending
  on the role

Module 2: Admin Module
- View all users in a list
- Add a new user
- Update a selected user (username / password)
- Remove a selected user
- Logout / Exit

Module 3: User Module
- Shows the welcome message and the user's current score
- Lists all problems as radio buttons
- Submits a Java solution file through a file chooser
- Compiles the file with javac
- Runs the compiled class with the problem's test input
- Compares the output with the expected output
- Updates the score when the problem is solved for the first time
- Shows the leaderboard of all users

Module 4: Database Module
- Connects to the MySQL database using JDBC
- Contains the DAO classes (UserDAO, ProblemDAO, SubmissionDAO)
  for all database operations

5. DATABASE SCHEMA

Database: judge

Table: users
  user_id INT AUTO_INCREMENT PRIMARY KEY
  username VARCHAR(30) NOT NULL UNIQUE
  password_hash VARCHAR(255) NOT NULL
  score INT DEFAULT 0
  role ENUM('USER', 'ADMIN') DEFAULT 'USER'

Table: problems
  problem_id INT AUTO_INCREMENT PRIMARY KEY
  title VARCHAR(100) NOT NULL
  points INT NOT NULL

Table: submissions
  submission_id INT AUTO_INCREMENT PRIMARY KEY
  code LONGTEXT NOT NULL
  language VARCHAR(30) NOT NULL
  submitted_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
  verdict VARCHAR(30)
  user_id INT NOT NULL (FK)
  problem_id INT NOT NULL (FK)

Sample data:
- admin user (role ADMIN)
- problems: Sum Two Numbers (1 point),
  Sort Array (2 points), Reverse Array (1 point)

8. FULL WORKING CRUD

Create (Insert):
- Admin adds a new user (INSERT INTO users)

Read (View):
- Admin and User see all users with scores (SELECT)
- Problems are loaded from the database

Update:
- Admin updates username and password of a selected user
- User score increases when solving a problem

Delete:
- Admin removes a selected user (DELETE FROM users)

All CRUD operations are working with the MySQL database through
the DAO classes.
